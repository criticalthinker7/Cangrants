# CanGrants design direction

## Selected direction

CanGrants should move toward a light green and white product experience with restrained blue accents:

- Background: soft green `#F7FBF8`
- Primary surfaces: white `#FFFFFF`
- Muted surfaces: pale green `#EEF7F1`
- Primary green: `#2F6F4E`
- Deep text green: `#163325`
- Blue accent: `#2D6CDF`

This keeps the arts funding experience approachable and calm while preserving enough contrast for dashboard navigation, grant cards, and calls to action.

## Rationale

The previous darker dashboard language made CanGrants feel more like a campaign landing page than a daily-use grants workspace. The selected light palette better supports scanning dense information: deadlines, grant metadata, filters, saved opportunities, and application status.

Green remains the core brand signal because it fits grants, growth, and Canadian arts support. White surfaces give grant records and forms clearer hierarchy. Blue should be used sparingly for accents, especially international items and high-value actions, so it adds clarity without competing with the primary green system.

## Next design improvements

- Build a small set of reusable card, button, and field style patterns from the new theme values.
- Normalize spacing and border treatment across Discover, Saved, Applications, Assistant, and Contact.
- Revisit chart, badge, and status colors so deadlines and application states remain accessible on the lighter background.
- Add responsive header behavior for narrow screens as the tab set grows.
- Review typography scale after the palette settles, keeping navigation tabs readable and workspace labels compact.
